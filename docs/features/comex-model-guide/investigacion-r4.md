## Precios y revisiones

Se mantienen los precios de la conexión como referencias de facturación. No se agregan tarifas universales: Go publica precios distintos por contexto, horarios y promociones. Suscripción no significa uso ilimitado. El anuncio de redirección de DeepSeek describe la API de DeepSeek; no prueba la ruta de OpenCode Go. Los nombres gratuitos y Contributor no se tratan como nuevos modelos con capacidades demostradas por su precio.

Las búsquedas de Big Pickle también devolvieron una prueba individual autodeclarada de SWE Atlas: no se adoptó por falta de trazas completas y por no confirmar la revisión del alias actual. Pulse Alpha tiene ficha comercial, sin una evaluación primaria suficiente hallada en esta revisión.

Cobertura al publicar: 18 referencias evaluadas, 22 estimaciones, 2 sin evidencia suficiente. El siguiente release o JSON estático puede corregir cada entrada e incrementar la revisión.
