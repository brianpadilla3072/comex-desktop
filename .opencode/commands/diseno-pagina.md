---
name: diseno-pagina
description: Crear o modificar una página/pantalla siguiendo el sistema de diseño de marca del proyecto
---

El usuario quiere una página o pantalla que siga el sistema de diseño de marca del
proyecto. Cargá `.opencode/skills/diseno-sistema-marca/SKILL.md` y el contexto del
sistema (tokens, componentes, guías). Creá o editá la página en el diseño activo
usando **solo** las variables y componentes del sistema (nunca un hex suelto ni un
estilo inventado). Si el proyecto no tiene un diseño de kind `system`, avisá y
ofrecé armarlo primero con `/diseno-marca`.

Argumentos: `$ARGUMENTS` (qué página/pantalla y para qué).
