---
name: diseno-doc
description: Crear un documento/presentación que siga el sistema de diseño de marca del proyecto
---

El usuario quiere un documento (slides o mockup) que siga el sistema de diseño de
marca. Cargá `.opencode/skills/diseno-sistema-marca/SKILL.md` y el contexto del
sistema. Creá el diseño (kind slides o mockup) con las páginas siguiendo los
tokens y componentes; nunca un estilo suelto. Si falta el sistema, ofrecé armarlo
con `/diseno-marca`.

Argumentos: `$ARGUMENTS` (qué documento y para qué).
